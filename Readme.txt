Guess the Number Game

This is a simple "Guess the Number" game built using Python and Tkinter for the graphical user interface (GUI). The game generates a random number between 1 and 100, and the player must guess the correct number with hints provided after each attempt.

Features

Random number generation between 1 and 100

Graphical user interface using Tkinter

Provides feedback for each guess (too high, too low, or correct)

User can submit guesses by clicking the button or pressing the Enter key

Displays the number of attempts taken to guess correctly

Requirements

Make sure you have the following installed:

Python 3.x

Tkinter (comes pre-installed with Python)

Files

guess_the_number.py: The main game script.

README.md: This file with game details.

How to Run

Clone the repository:

git clone https://github.com/yourusername/guess-the-number-game.git
cd guess-the-number-game

Run the game using Python:

python guess_the_number.py

How to Play

Enter a number between 1 and 100 in the input field.

Press "Enter" or click "Submit Guess".

Follow the hints provided until you guess the correct number.

Once you guess correctly, the game will display the number of attempts and close.
